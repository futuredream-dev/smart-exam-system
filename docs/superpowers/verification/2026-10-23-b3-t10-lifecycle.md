# B3 / T10 考试阶段统一

2026-10-23，北京时间；隔离分支 `codex/system-optimization`，起点 `d21f4c8`。本批处理 F15，教师导航与详情布局重构 T11 尚未开始。

## 解决的问题

- 已结束且无人交卷的考试显示“无人参加”，从待发布任务移出，在已完成列表可查看并归档、恢复，不需要先发布空成绩。
- 全客观题答卷完成自动评分后，工作台、考试中心、详情、成绩分析和管理员使用一致的完成事实。原答卷状态仍可为 SUBMITTED / AUTO_SUBMITTED，读取页面不会把它改成 GRADED。
- 简答题仍未人工复核、缺少答案行、客观题尚未完成自动评分或仍有进行中答卷时，不冒充可以发布成绩。历史缺失简答答案在答卷列表也保持待阅。
- 发布接口同时拒绝零交卷和已归档考试，保留原整场事务、锁、到期自动交卷与重算。归档考试需要先恢复，再按正常资格发布。
- 业务 `status` 不因界面阶段而修改；NO_PARTICIPANTS 只是派生值，没有新增数据库枚举、迁移或历史数据改写。

## 实现与兼容

`ExamLifecyclePolicy.evaluate(exam, Counts, now)` 统一返回 displayStage、nextAction、canReleaseResults、releaseBlockReason。时间取现有 UTC Clock，按 Asia/Shanghai 解释既有考试日期。

新增共享 `ExamLifecycleRepository` 按场次批量统计候选、进行中、已交、待人工评分、评分完成、已发布数量。评分完成要求各题的实际答案具备 AUTO_GRADED / REVIEWED 状态；不再只数 submission.status=GRADED。客观题缺答案仍阻止就绪，简答缺答案仍计为待阅。

教师 workspace 保留原 lifecycleStatus 和原始状态分类计数，新增 displayStage、nextAction、gradedCount；工作台已评分数量取 gradedCount。考试中心新增发布资格和原因，并在列表保留业务 status。管理员保留原业务筛选和 examStatuses，另加实时 displayStage / examStages；AdminPlatformService 继续委派现有 repository，无需为改动文件清单而制造额外转发层。

成绩分析使用相同完成事实。分析可读与发布资格分开：已发布、已归档或无人交卷仍可看合法的只读统计，不因此重新允许发布。已就绪时显示原保存的最终总分，不写回分数、评分状态或发布时间。
