# B3 / T11 教师任务界面优化验收记录

日期：2026-10-23。实施范围：独立分支 `codex/system-optimization`，基于 `2a3e5ec` 的本轮工作区变更；最终本地提交以 Git 历史为准。原工作区没有用于实施或写测试。本报告是 T11 批次记录，不代表整个系统或 B2 故障矩阵全部验收。

## 本轮更改

- 教师一级导航从六项收为“工作台、考试管理、题库管理、课程管理”。旧阅卷任务和 AI 分析路由保留，通过工作台、考试详情进入，且明确显示返回入口。
- 工作台展示待阅卷、即将开考、待发布成绩，另列进行中考试。每组最多显示五场，显示总量及查看全部入口。“即将开考”由后端兼容新增 `upcoming` 字段，复用 T10 阶段判断，只包含教师所属课程中未归档的待开始考试，按开始时间、ID 排序。未改表结构。
- 考试页头保留名称、课程、阶段、时间和一个主要动作；移除重复的六步进度条和顶部四块摘要，将规则、统计和创建补考移入概览。
- 考试栏目为“概览、试卷、考生与考务、阅卷、成绩”。草稿默认试卷，进行中默认考务，结束待阅默认阅卷，阅完与已发布默认成绩。旧 `overview/paper/candidates/grading/monitor` 参数分别保留原内容；其中 monitor 进入考生与考务下的监控子栏目，grading 仍为成绩。
- 组卷一级入口为“从题库组卷、手动出题”，题库子区域保留手动选题、随机、规则、AI 四种方式及说明；原组件和后端约束保留。
- 阅卷栏目专注答卷列表，成绩栏目负责发布、导出和分析。面板的旧默认模式保留，当前详情使用明确模式，避免重复列表与发布区域。
- 考试详情携带原列表筛选及页码；切换栏目不丢返回上下文。阅卷下一份和最后一份携带原任务筛选。AI 分析定位所选考试，返回对应考试，避免原先静默打开第一场。
- 教师同路径查询变化复用页面，不同 examId/submissionId 路径重新创建页面。学生保留原 fullPath 键；没有修改角色守卫。
- 390 宽度教师导航使用两列，长标题换行，组卷方式单列，焦点可见；沿用原蓝色视觉体系，无新增依赖或锁文件变动。
- 更新管理员旧结构检查：承认现有五项管理职责，保留管理员不调用教师/学生业务 API 和不出现教师导航的断言。
