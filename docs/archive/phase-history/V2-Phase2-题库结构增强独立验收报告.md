### FAIL-1｜批量 metadata 在浏览器中 100% 不可用：CORS 未允许 `PATCH`（阻塞 Phase 2）

> **状态更新（2026-09-24 追加）**：Codex 已修复 `WebConfig.allowedMethods(...)` 加入 `PATCH`，本项**已定向复验通过**，详见文末《九、Phase 2 Hotfix 复验》。本节保留原始记录以保持验收可追溯性。

- **严重程度**：高 —— **阻塞**。Phase 2「批量维护」能力（任务十五、十六）在开发环境前端完全无法使用。
- **操作步骤**：
  1. 教师登录 → 题库管理 → 进入 `Phase2结构化题库(1633)`；
  2. 勾选 3 道题（页面正确显示「已选择 3 道题」）；
  3. 点击「批量设置」→ 选择「设置章节」→ 目标章节「集合框架 / Map」→「查看变更」；
  4. 面板显示「将修改 3 道题。其余分类信息保持不变。」→ 点击「确认修改 3 道题」。
  5. 同样方式再试「设置难度 = 困难」。
- **实际结果**：面板显示 **`批量操作失败`**，题目数据无任何变更，选择状态保留。
- **预期结果**：批量设置成功，3 道题 metadata 更新，页面刷新、选择状态清空。
- **前端表现**：仅一行 `批量操作失败`（`p.error-message[role=alert]`），无具体原因；无白屏、无控制台崩溃。
- **HTTP 状态**：`PATCH /api/teacher/question-banks/1633/items/batch-metadata` → **403**（两次尝试均 403）。
  根因定位（只读查阅，未修改）：`GET /api/...batch-metadata` 的 CORS 预检 `OPTIONS` 携带 `Access-Control-Request-Method: PATCH` 时被后端拒绝：

  ```
  OPTIONS /api/teacher/question-banks/1633/items/batch-metadata
  Origin: http://localhost:5173
  Access-Control-Request-Method: PATCH
  → HTTP 403  "Invalid CORS request"
  ```
