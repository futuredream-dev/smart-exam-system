# 历史开发资料

[phase-history/](phase-history/) 保存早期 V1 设计、阶段实施计划和验收记录。这些文件反映当时的范围、数据和结论，可能包含已过期的表数、接口或运行方式，**不作为当前部署与使用依据**。

当前入口请从项目根目录 [README](../../README.md)、[数据库说明](../../sql/README_数据库共享说明.md)、[部署说明](../04_部署与运行说明.md) 以及 [本地环境变量示例](../../config/local.env.example) / [Compose 环境变量示例](../../.env.example) 开始。新数据库只执行 `sql/init.sql`；历史升级脚本的适用边界见数据库说明。
