# 本地运行说明

本文补充根目录 [README](../README.md) 的 Windows 本地运行与故障排查。命令默认在项目根目录的 PowerShell 执行。

## 环境准备

需要 JDK 17、Node.js 20 及以上、pnpm，以及运行中的 MySQL 8.0.16 及以上。java、node、pnpm 应能从 PATH 调用。启动脚本使用 PATH 或 MAVEN_HOME 中的 Maven；未找到时下载并校验 Maven 3.9.9 到被 Git 忽略的 .runtime/tools，首次下载需要网络。

确保 MySQL 监听本机 3306。脚本只检查数据库连通性，不会启动或修改系统的 MySQL 服务。若本机服务名称不确定，请在 Windows“服务”中查找并启动。

## 全新数据库与本地配置

在项目根目录打开 MySQL 命令行：

~~~powershell
mysql -u root -p --default-character-set=utf8mb4
~~~

在 MySQL 提示符依次执行：

~~~sql
SOURCE sql/init.sql;
SOURCE sql/demo-data.sql;
~~~

init.sql 是一次性的全新建库入口，创建 smart_exam 与 19 张表；demo-data.sql 可在受控演示库重复运行，保留已有考试状态和答卷。不要对已有业务库执行这两步。历史库迁移见[数据库说明](../sql/README_数据库共享说明.md)。

首次复制本地模板；已有本地配置时不要覆盖：

~~~powershell
Copy-Item config/local.env.example config/local.env
~~~

在 config/local.env 中填写 DB_PASSWORD 和至少 32 字符的高熵 JWT_SECRET。数据库主机、端口、库名和用户可按实际情况修改。脚本读取此文件，已有进程环境变量优先。不要将真实凭据写入 README、源码或提交到 Git。

AI_BASE_URL、AI_API_KEY、AI_MODEL 都配置时，才能请求兼容模型服务。未配置仍可使用规则组卷与人工阅卷。使用 Demo 数据时已存在管理员，无需再填写 ADMIN_* 初始管理员参数。

## 启动与访问

按需分别执行：

~~~powershell
.\scripts\dev.ps1 -Action start
.\scripts\dev.ps1 -Action check
.\scripts\dev.ps1 -Action stop
~~~

start 会检查 Java、Node、pnpm、MySQL、必需密钥和端口；准备 Maven 并打包后端，在缺少前端依赖时执行锁文件安装，然后启动后端和 Vite。等待健康端点和前端页面就绪后才报告成功。可在 start 后附加 -NoBrowser。项目的进程状态和日志位于被 Git 忽略的 .runtime/；不要分享未经检查的日志。

- 前端登录页：http://localhost:5173/login
- 后端 API：http://localhost:8080/api
- 健康检查：http://localhost:8080/actuator/health

脚本约定 MySQL 3306、后端 8080、前端 5173。它不会改用其他端口，也不会停止占用端口的其他程序。stop 只处理本项目脚本记录且核实归属的进程，不停止 MySQL 或从 IDE 手工启动的服务。

## 手工开发

直接运行后端时，要先在同一终端提供 DB_* 与 JWT_SECRET；Maven 不会自动加载 config/local.env：

~~~powershell
$maven = .\scripts\ensure-maven.ps1
& $maven -f backend/pom.xml spring-boot:run
~~~

另开终端安装并运行前端：

~~~powershell
Push-Location frontend
pnpm install --frozen-lockfile
pnpm dev
~~~

前端构建：

~~~powershell
Push-Location frontend
pnpm build
Pop-Location
~~~

## 常见问题

| 现象 | 检查 |
|---|---|
| 数据库连接失败 | MySQL 是否运行；DB_HOST、DB_PORT、DB_NAME、DB_USERNAME、DB_PASSWORD 是否与实际一致；全新库是否已执行两份 SQL |
| JWT_SECRET 缺失 | 在 config/local.env 或当前进程环境中设置至少 32 字符的随机值 |
| 8080 或 5173 被占用 | 先关闭已有的 IDE 后端或 Vite；脚本不会占用 5174 来绕过冲突 |
| 前端请求失败 | 先访问健康检查，再确认 Vite 代理的后端端口仍为 8080 |
| AI 请求失败 | 检查三项 AI 环境变量与模型服务可用性；人工阅卷和规则组卷仍可继续 |
| 首次 Maven 下载失败 | 检查网络，或安装 Maven 并放入 PATH / MAVEN_HOME |
| 登录演示账号失败 | 确认在目标演示库运行了 demo-data.sql，并检查应用实际连接的 DB_NAME |

历史测试数量和运行记录不代表当前执行结果；以本次命令与日志为准。
