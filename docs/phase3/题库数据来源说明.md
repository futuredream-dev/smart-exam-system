# Java 主题库 Final-B 题目来源

本批 30 道题以《Java, Java, Java: Object-Oriented Problem Solving, 2024E》的练习及活动为来源。作者：Ralph Morelli、Ralph Walde、Beryl Hoffman、David G. Cooper。原教材和许可见 [Runestone 教材](https://runestone.academy/ns/books/published/javajavajava/book-1.html)、[作者代码仓库](https://github.com/ram8647/javajavajava)及 [CC BY 4.0 许可](https://github.com/ram8647/javajavajava/blob/master/LICENSE)。

每题的原书章节、可定位练习号、原始链接和 Java SE 17 复核入口记录于本地来源清单 `Java主题库-FinalB来源清单.csv`。该清单及题库文件尚未纳入 Git，公开发布前需单独完成授权和内容复核；因此当前仓库不提供逐题清单链接。Excel 题号 FB001—FB030 与清单逐行对应。题目均译成中文并适配为单选或简答，选择题备选项及简答评分点为本项目的格式适配；不声称原作者认可本项目。未从未授权题库复制，也未把改编题说成原文逐字题。

Java 语义另按 Oracle Java SE 17 官方文档复核，重点包括 [线程状态](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/lang/Thread.State.html)、[输入输出](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/io/package-summary.html)、[集合](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/util/package-summary.html)、[异常规范](https://docs.oracle.com/javase/specs/jls/se17/html/jls-11.html)、[字符串](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/lang/String.html)。特别避免沿用教材中可能过时的线程 API 叙述。
